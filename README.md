Описание задания

Настройка окружения разработки, создание простого HTTP-сервера, его контейнеризация с помощью Docker и запуск через docker-compose.yml.

Результат доступен по адресу: http://localhost:8000

Как запустить проект

Клонировать репозиторий:

git clone https://github.com/Kantanistka/web2026.git
cd lab1


Запустить контейнеры:

docker-compose up -d --build


Открыть в браузере: http://localhost:8000

Содержимое проекта

Dockerfile — инструкция по сборке Docker-образа с HTTP-сервером Nginx

docker-compose.yml — описание сервиса и проброса портов (8000:80)

index.html — главная HTML-страница

screenshots/ — скриншоты работы сервера и анализа HTTP-запросов

Результат: Сервер в Docker успешно запущен, Nginx отдаёт HTML-страницу по порту 8000, структура HTTP-запроса проанализирована.
